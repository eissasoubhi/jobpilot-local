# Michael Page

## Statut JobPilot

`EMAIL_OR_EXTENSION_ONLY`

Revue effectuée le **29 août 2026**.

## Décision

Michael Page expose publiquement un catalogue d’offres consultable sans authentification, mais JobPilot n’active pas de collecte planifiée HTTP ou navigateur pour cette source.

Les conditions générales d’utilisation Michael Page décrivent le site comme mis à disposition pour un **usage personnel**. Elles autorisent l’affichage du contenu, une conservation locale limitée et l’impression pour un usage personnel et non commercial, mais interdisent de reproduire, modifier, copier, distribuer ou utiliser commercialement le contenu sans autorisation écrite.

Aucune API, aucun flux RSS/Atom ni export officiel de lecture/réutilisation du catalogue candidat n’a été identifié pendant cette revue.

La visibilité publique des offres ne constitue donc pas, à elle seule, une base suffisante pour ajouter un scraper planifié JobPilot. Le choix conservateur est de garder Michael Page sur les voies assistées déjà admises :

- alertes emploi reçues par Gmail lorsqu’elles sont disponibles et reconnues ;
- import volontaire d’une page ouverte par l’utilisateur via l’extension/import assisté.

Aucun login automatisé, cookie privé, endpoint non documenté, scraper HTTP/Browser ou contournement de protections ne doit être introduit pour Michael Page dans cet état.

## Condition de réouverture

Cette décision peut être revue si Michael Page publie un canal officiel de lecture/réutilisation des offres applicable à JobPilot, ou accorde une autorisation écrite explicite permettant une collecte automatisée planifiée.
