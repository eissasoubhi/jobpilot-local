# Product naming evaluation

## Decision status

No rename is approved yet. The product remains **JobPilot** until a dedicated branding decision is made.

## JobPilot

Strengths:
- clear product promise: an assistant/pilot for the job-search workflow;
- more distinctive and product-like than a generic job portal name;
- fits the current product behavior: guided discovery, ranking, preparation, review and follow-up.

Risks:
- the name is already used by several current products, including job-search tools and a local-first AI job-search project;
- a public/commercial launch could create discoverability, confusion and brand-clearance problems.

## JobHub

Strengths:
- communicates a central workspace for offers, applications, recruiter messages and reporting;
- broad enough for the product's multi-module direction.

Risks:
- much more generic;
- already widely used by job boards, recruitment apps, websites and open-source projects;
- sounds more like a marketplace/job portal than a personal intelligent job-search workspace;
- weaker differentiation for SEO, app stores and word-of-mouth.

## Recommendation

Do **not** rename JobPilot to JobHub.

If the product remains private/local, keeping JobPilot is reasonable.

If the goal is a public product, SaaS, packaged desktop product or marketed open-source project, choose a third, more distinctive name before publication rather than moving from one crowded name to an even more generic crowded name.

## Before approving any public rename

1. Build a shortlist of 5-10 distinctive candidates.
2. Check web search and direct competitors.
3. Check GitHub/project-name collisions.
4. Check relevant domain availability.
5. Check app stores/package registries where applicable.
6. Perform an appropriate trademark/name clearance for target markets before commercial launch.
7. Only then open a dedicated rename PR covering UI, metadata, extension, local domain, docs, config/event compatibility and rollback.
