Politique de confidentialité

Protection des données sur le site public

Cette page publique présente le projet JobPilot. Elle est séparée de l'application locale qui contient les données privées de l'utilisateur.

Données collectées sur ce site

Le site public ne contient aucun formulaire, aucun compte utilisateur, aucun cookie publicitaire et aucun outil d'analyse comportementale. Il ne demande ni nom, ni adresse e-mail, ni CV, ni information de candidature.

Journaux techniques de l'hébergeur

L'hébergeur peut traiter des données techniques nécessaires à la sécurité et à la fourniture du site, par exemple l'adresse IP, le navigateur, la date de la requête et l'URL consultée. Ces traitements relèvent de la politique de l'hébergeur choisi pour le déploiement.

Données de l'application JobPilot

Les CV, offres enregistrées, messages, candidatures, notes, paramètres et identifiants API ne sont pas hébergés sur ce site public. Ils restent dans l'environnement privé de l'utilisateur de JobPilot.

Utilisation des API

JobPilot peut utiliser des API officielles pour récupérer des offres d'emploi. Les identifiants d'accès sont stockés dans l'environnement privé de l'application et ne sont jamais intégrés au code ou au site public.

Contact et exercice des droits

Pour toute question relative à cette page, la demande peut être adressée au propriétaire de l'application indiqué dans le compte France Travail.io utilisé pour enregistrer JobPilot.
